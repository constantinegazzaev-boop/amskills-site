# Развёртывание на российском (PHP) хостинге

Эта папка — серверная часть для обычного хостинга вместо Vercel. Статические файлы сайта лежат в корне репозитория,
а здесь только то, чего нет на Vercel: `.htaccess` и PHP-версии платёжных функций (`api/*.php`, аналоги `api/*.js`).

## Сборка архива для загрузки

```bash
python3 scripts/build-hosting-zip.py   # создаёт amskills-hosting.zip в корне (в git не попадает)
```

В архив входят страницы, `css/`, `js/`, `img/`, `fonts/`, `.htaccess` и `api/` (без config.php и без Node-файлов).

## Развёртывание

1. Загрузить архив в папку сайта на хостинге и распаковать (файловым менеджером панели).
2. В папке `api` скопировать `config.sample.php` в `config.php` и вписать ключ и пароль боевого терминала Т-Кассы,
   `site_url` (адрес, где открыт сайт), при необходимости `taxation` (по умолчанию `patent`) и `vat` (по умолчанию `none`).
3. Включить в панели хостинга бесплатный SSL и принудительный переход на HTTPS.
4. Проверить: главная, оферта, оплата на небольшую сумму, возврат в кабинете Т-Кассы.
5. В кабинете Т-Кассы адрес уведомлений: `https://<домен>/api/payment-notification`.

## Как это устроено

- `.htaccess` отдаёт `/api/payment-init` и `/api/payment-notification` из PHP-файлов, редиректит www → без www и старые адреса
  Tilda (`/politika`, `/oplatarazovoytrenirivki`, `/application3`, `/application4`) на новые страницы.
- `api/lib.php` — подпись Т-Кассы, проверка e-mail и телефона, запрос к API (cURL, при ошибке сертификата повтор с
  корневым сертификатом Минцифры из `russian-trusted-ca.pem`).
- Поведение совпадает с Node-версией: чек (`Receipt`) в запросе, при отказе Т-Кассы платёж создаётся без чека, e-mail и телефон в лог не пишутся.
- Для автотестов в `lib.php` есть подмены `$GLOBALS['TK_HTTP']` (транспорт), `$GLOBALS['TK_INPUT']` (тело запроса)
  и `$GLOBALS['TK_LAST_STATUS']` (код ответа). Нужен PHP 7.2+ с расширениями curl и json.
