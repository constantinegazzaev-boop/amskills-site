# AMSkills — сайт школы индивидуальной подготовки

Статический одностраничник (HTML/CSS/JS) + serverless-функции для приёма оплаты через Т-Кассу.

## Структура

- `index.html` — вся страница
- `css/styles.css` — стили (цвета — в `:root` вверху файла)
- `js/main.js` — мобильное меню + отправка формы оплаты
- `api/payment-init.js` — создаёт платёж в Т-Кассе, отдаёт ссылку на оплату
- `api/payment-notification.js` — принимает webhook от Т-Кассы о статусе платежа
- `success.html` / `fail.html` — страницы после оплаты

- [ ] Ключи Т-Кассы — `TINKOFF_TERMINAL_KEY` и `TINKOFF_PASSWORD` (см. `.env.example`)

## Запуск локально

Простой способ — открыть `index.html` в браузере (форма оплаты работать не будет без backend).

Для проверки оплаты нужен Node-сервер. Проще всего через Vercel CLI:

```bash
npm i -g vercel
vercel dev
```

## Деплой (рекомендация — Vercel)

1. `vercel` в корне проекта — задеплоит сайт и API как есть, бесплатно
2. В настройках проекта на vercel.com → Environment Variables добавить:
   - `TINKOFF_TERMINAL_KEY`
   - `TINKOFF_PASSWORD`
   - `SITE_URL=https://amskills.ru`
3. В настройках домена на Vercel подключить `amskills.ru` (Vercel выдаст DNS-записи — их нужно прописать там, где сейчас настроен домен)
4. В личном кабинете Т-Кассы указать URL для уведомлений (`Notification URL`): `https://amskills.ru/api/payment-notification`

Текущий сайт сделан на Tilda — после переключения DNS на Vercel Tilda-версия перестанет открываться по этому домену.
